A fetch tool written in bash scripting for bash3.2 in order to use with Mac OS X Snow Leopard. To use, just execute the script. 

Other versions of Mac OS is not tested and support for them will not be added. This fetch tool is only for Snow Leopard, and that's it.

If fonts are broken, please make Terminal.app (or your term) use Nerd Fonts.
