A fetch tool written in bash scripting for bash3.2 in order to use with Mac OS X Snow Leopard. To use, just execute the script. 

Other versions of Mac OS are not tested and support for them will not be added. This fetch tool is only for Snow Leopard, and that's it.

If fonts are broken, please make Terminal.app (or your term) use Nerd Fonts.

<img width="1280" height="800" alt="snowfetch" src="https://github.com/user-attachments/assets/5d8b941a-0e6b-41f2-85f6-8a546940f3a0" />

As you can see, it shows:

- An ASCII art of Apple logo,
- OS name and version,
- Kernel version and arch,
- Init,
- Uptime,
- Packages (pkgutil, macports and brew),
- Applications (Applications/ folder),
- Shell,
- DE (which is always Aqua on macOS),
- Terminal app and build,
- CPU,
- GPU,
- RAM and usage,
- HDD and usage,
- Colors.
